================================================================================
          دليل مهندس الواجهات وتجربة المستخدم (Frontend Developer Guide)
================================================================================

مرحباً بك! هذا المجلد يحتوي على كافة ملفات الواجهة الأمامية والتصميم الخاصة بك.
المستودع الرسمي للمشروع على GitHub:
https://github.com/hrnafifgit/Studio_Image_SE.git

اسم الفرع المخصص لك في Git:
feature/frontend-studio

--------------------------------------------------------------------------------
1. محتويات هذا المجلد المسندة إليك:
--------------------------------------------------------------------------------
- resources/views/ : قوالب الواجهات (welcome.blade.php وواجهة استوديو الصور)
- public/js/       : ملفات الجافاسكربت (أكواد الـ Canvas، التفاعل، الـ AJAX، معالجة الطبقات)
- public/css/      : ملفات التنسيق والتصميم وأشرطة الأدوات
- public/          : الأصول والملفات الإضافية (accessories/, backgrounds/, samples/, bee_logo)
- package.json     : أدوات وباقات الواجهة
- vite.config.js   : إعدادات مجمع الـ Assets

--------------------------------------------------------------------------------
2. خطوات رفع عملك إلى GitHub بالتفصيل:
--------------------------------------------------------------------------------

[الخطوة الأولى: إعداد هويتك في Git (مرة واحدة فقط)]
افتح موجه الأوامر (CMD أو PowerShell) ونفذ الأمرين التاليين بحسابك الخاص في GitHub
(لكي يسجل الدكتور الإسهامات والدرجات باسمك):
git config user.name "اسمك_الرباعي"
git config user.email "your-email@example.com"


[الخطوة الثانية: طريقة رفع الملفات إلى فرعك feature/frontend-studio]

1. قم بسحب (Clone) للمستودع في مجلد على جهازك:
   git clone https://github.com/hrnafifgit/Studio_Image_SE.git
   cd Studio_Image_SE

2. أنشئ فرعك الخاص وانتقل إليه فوراً:
   git checkout -b feature/frontend-studio

3. انسخ الملفات الموجودة في هذا المجلد وضعها داخل مجلد المشروع Studio_Image_SE.

4. أضف ملفات الواجهة الأمامية إلى Git:
   git add resources/ public/ package.json vite.config.js

5. احفظ التعديلات (Commit) برسالة واضحة:
   git commit -m "feat(frontend): build studio UI, interactive canvas controls, and ajax integration"

6. ارفع فرعك إلى مستودع GitHub:
   git push -u origin feature/frontend-studio


[الخطوة الثالثة: فتح طلب الدمج (Pull Request)]
1. ادخل عبر المتصفح إلى رابط المستودع:
   https://github.com/hrnafifgit/Studio_Image_SE
2. ستظهر لك في الأعلى لافتة خضراء أو صفراء تذكر فرعك: feature/frontend-studio.
3. اضغط على الزر: [ Compare & pull request ].
4. في خانة العنوان اكتب: "تصميم وبناء واجهات الاستوديو وأدوات تحرير الصور".
5. في خانة الوصف اكتب تفاصيل ما قمت به (تصميم الواجهة، دوال الجافاسكربت، الاستجابة للشاشات).
6. اضغط على الزر الأخضر: [ Create pull request ].

تهانينا! هكذا تم توثيق عملك رسمياً في المستودع المشترك باسمك أمام الدكتور.
